# 배드민턴 영상 코치

휴대폰에서 경기 영상을 올리고, 경기 운영·자세·기술에 관한 리포트와 후속 코칭을 받는 개인용 harness agent입니다. Open WebUI를 채팅 화면으로 사용하고, Windows PC가 영상·작업·개인 기억을 보관합니다.

## 주요 기능

- 경기 리포트: **전체 특징 → 관찰된 수준 → 잘한 점 → 아쉬운 점 → 개선·연습 계획**
- 경기 운영·전술 또는 기술·자세를 선택해 분석. 강습·난타에는 목적별 형식 적용
- 전체 리뷰는 **전체 코트 2fps·1280px**, 빠른 동작은 짧은 구간의 **원본 연속 프레임·원본 해상도**로 보완
- 모델이 실제 영상 도구를 선택·실행하며 원본 시각과 근거를 저장·재사용
- 일반 그립 질문은 영상 없이 답하고, 저장 리포트 설명과 새 장면 확인을 구분
- 큰 영상은 **4MiB 분할 전송·자동 재시도·같은 파일 재선택 후 이어 올리기**
- 브라우저를 닫은 뒤에도 시작된 분석을 PC에서 계속하고 `결과`로 조회
- 새 채팅에서도 같은 계정의 프로필·과거 코칭·연습 경과를 참고하는 개인 기억

## 평소 사용

1. PC에서 `지금실행.cmd` 또는 바탕화면 **배드민턴 코치 실행**을 더블클릭합니다.
2. PC는 `http://127.0.0.1:8080`, 휴대폰은 같은 Tailscale 계정의 개인 HTTPS 주소로 접속합니다.
3. Open WebUI의 **배드민턴 코치** 모델에서 일반 채팅을 열고 영상을 첨부합니다.
4. 업로드 완료 후 본인의 옷·코트 위치와 분석 목적을 함께 말합니다.

> 경기 영상이야. 검은 상하의가 나야. 경기 운영을 중심으로 전체 특징, 내 수준, 잘한 점, 아쉬운 점, 개선 계획을 리포트로 정리해줘.

일반 질문은 영상을 올리지 않아도 됩니다. 임시 채팅은 지원하지 않습니다. 휴대폰 업로드 중에는 브라우저를 열어 두고, 업로더 업데이트 후에는 페이지를 한 번 새로고침하세요.

| 명령 | 역할 |
|---|---|
| 결과 / 상태 | 저장 보고서 또는 진행 상태 조회, 새 모델 호출 없음 |
| 리뷰계속 | 같은 리뷰의 남은 예산으로 재개 |
| 리뷰계속 1.00 | 같은 리뷰에 사용자가 명시한 USD 1.00 추가 |
| 취소 | 진행 중 분석 취소 요청 |
| 영상목록 / 영상삭제 1 | 현재 채팅의 영상 관리 |
| 기억목록 / 기억저장 내용 / 기억수정 ID 내용 / 기억삭제 ID | 개인 기억 확인·저장·정정·삭제 |
| 성장기록 내용 / 기억전체삭제 / 기억끄기 / 기억켜기 | 연습 경과와 기억 사용 관리 |

## 새 PC 설치

지원 기준: **Windows·Python 3.12·FFmpeg/FFprobe**. 원격 사용에는 Tailscale, 모델 호출에는 사용 가능한 OpenAI API 키가 필요합니다. 아래 명령은 프로젝트 폴더에서 실행합니다.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.lock.txt
# FFmpeg/FFprobe를 PATH 또는 FFMPEG_PATH·FFPROBE_PATH로 준비합니다.
# 인증등록.cmd를 실행해 Windows 자격 증명에 API 키를 등록합니다.
.\.venv\Scripts\python.exe -m badminton.operations setup
.\.venv\Scripts\python.exe -m badminton.operations shortcut
.\.venv\Scripts\python.exe -m badminton.operations launch
```

최초 실행 시 Open WebUI 관리자 계정을 만들고, 휴대폰은 `휴대폰연결.cmd`로 개인 HTTPS 주소를 설정합니다. 이미 구성된 PC에서는 다시 설치하지 말고 `지금실행.cmd`를 사용하세요. 고정 의존성은 개발 PC의 환경 스냅샷이며 다른 OS의 범용 설치를 보장하지 않습니다.

## 데이터·모델·비용

- 실행 데이터: `%LOCALAPPDATA%\BadmintonAgent`. `BADMINTON_DATA_DIR`로 개발 환경을 분리할 수 있습니다.
- 현재 기본 모델: `gpt-6-luna`. 설정·모델별 요금 스냅샷은 `badminton/config.py`, `badminton/pricing.py`가 기준입니다.
- 현재 기본 harness: **native Responses HTTP 도구 호출**. Hermes·stdio MCP 연결 코드는 있으나 이 PC에서 Hermes 통합 실행은 미검증입니다.
- 파일당 설정 한도: **4GiB·60분**, 주 사용 대상은 **15분 이내** 영상입니다.
- 최초 전체 리뷰 모델 API 상한: **USD 3.50/영상**. 정액 요금이 아니며 실제 사용량을 정산합니다. 일반·후속 질문 비용은 별도입니다.
- FFmpeg/PyAV·파일 전송·로컬 추출에는 모델 API 요금이 없습니다. 이미지 판독·분류·답변 생성에는 요금이 발생합니다.
- 키는 Windows 자격 증명, 내부 비밀값은 데이터 폴더에 저장합니다. 실제 영상·DB·로그·키를 Git에 커밋하지 않습니다.

## 검증

```powershell
# 불필요한 외부 pytest 플러그인 자동 로딩을 제외합니다.
$env:PYTEST_DISABLE_PLUGIN_AUTOLOAD = '1'
.\.venv\Scripts\python.exe -m pytest -q
```

자동 회귀 시험은 131개이며 실제 모델 호출이 없습니다. 1.55GiB 브라우저 전송·응답 유실·페이지 새로고침·이어 올리기·저장 해시와 채팅 연결을 검증했습니다. 이 전송 시험은 패딩한 MP4를 사용했으며 실제 휴대폰 5G 전송 성공과는 구분합니다.

`scripts`의 실제 모델 시험은 API 요금이 발생할 수 있습니다. 기존 캐시 발행 도구도 일반 기동용이 아닙니다. 실행 전 [시험 안내](docs/USER_GUIDE.md#11-업데이트와-개발-시험)를 확인하세요.

전체 2fps 시간대를 판독했다는 사실은 모든 타구·실수 검출이나 코칭 의미의 완전한 정확도를 뜻하지 않습니다. 수준은 해당 영상의 수행 추정이며, 정확한 득실점·셔틀 속도·악력·공식 급수는 측정하지 않습니다. 상세 검증과 한계는 [VALIDATION.md](VALIDATION.md)를 참고하세요.
